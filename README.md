# 🚀 Eventos en JavaScript - Tareas Diarias

¡Bienvenido al proyecto **Tareas Diarias**! 🎉  
Este es un proyecto simple pero poderoso que te permite gestionar tus tareas diarias utilizando JavaScript y eventos del DOM. Puedes agregar tareas, actualizarlas, eliminarlas individualmente o borrar todas las tareas de una sola vez. ¡Perfecto para organizar tu día! 📅

---

## ✨ Características Principales

- **Agregar Tareas**: Ingresa una hora y selecciona una tarea de la lista desplegable. 🕒
- **Visualización de Tareas**: Las tareas se muestran en un contenedor con la hora y la descripción. 📋
- **Actualizar Tareas**: Próximamente (en desarrollo). 🔄
- **Eliminar Tareas**: Elimina tareas individualmente o borra todas las tareas de una sola vez. 🗑️
- **Interfaz Intuitiva**: Diseño sencillo y fácil de usar. 🖥️

---

## 🛠️ Cómo Usar

1. **Ingresa la Hora**: Escribe la hora en el campo de entrada de tipo `time`. ⏰
2. **Selecciona una Tarea**: Elige una tarea de la lista desplegable. 📝
3. **Agrega la Tarea**: Haz clic en el botón **"Enviar"** para agregar la tarea al contenedor. ✅
4. **Elimina Tareas**: 
   - Elimina una tarea específica con el botón **"Eliminar"** en cada tarjeta. 
   - Elimina todas las tareas con el botón **"Eliminar Todo"**. 🗑️

---

## 🖥️ Ejemplo de Uso

1. Ingresa la hora `14:30` en el campo de entrada.
2. Selecciona la tarea **"Hacer ejercicio"** de la lista desplegable.
3. Haz clic en **"Enviar"**.
4. Verás una tarjeta con la hora `14:30` y la tarea **"Hacer ejercicio"**.
5. Puedes eliminar la tarea con el botón **"Eliminar"** o borrar todas las tareas con **"Eliminar Todo"**.
